工厂管理系统 - 部署与运行命令清单
============================================================

说明：
1. 以下命令均在「项目根目录」执行，默认使用 Windows CMD 语法。
2. 前置条件：已安装 Python 3 并加入 PATH；若使用 MySQL，请先启动 MySQL 服务。
3. 第 1~6 步是一次性部署；可以直接双击 deploy_env.bat 自动执行，也可以手动按顺序复制执行。
4. 部署完成后，双击 run_system.bat 启动服务；若想一次完成部署+启动，双击 启动系统.bat。


------------------------------------------------------------
一、一次性部署（按顺序执行）
------------------------------------------------------------

【1】创建虚拟环境（venv 已存在可跳过）
python -m venv venv

【2】升级 pip 并安装依赖
venv\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
venv\Scripts\python.exe -m pip install -r requirements.txt

【3】生成配置文件（.env 已存在可跳过；按实际情况修改数据库参数）
copy .env.example .env

【4】确保数据库存在（SQLite 配置会自动跳过；MySQL 会自动建库）
venv\Scripts\python.exe scripts\ensure_database.py

    如不使用上面的脚本，可手动执行等价 SQL：
    mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS FactoryManagementSystem DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

【5】执行数据库迁移（仓库已含全部迁移脚本，只 upgrade，不要重新 migrate）
venv\Scripts\python.exe -m flask db upgrade
venv\Scripts\python.exe -m flask db current

    当前 head 应为：e0f1a2b3c4d5

【6】写入种子数据（幂等，可重复执行；包含权限点、角色、管理员账号）
venv\Scripts\python.exe scripts\seed.py


------------------------------------------------------------
二、验证部署结果（可选）
------------------------------------------------------------
venv\Scripts\python.exe -m flask db current
venv\Scripts\python.exe -m pytest tests -q


------------------------------------------------------------
三、日常运行（部署完成后每次执行）
------------------------------------------------------------

方式 A（推荐）：双击 run_system.bat

方式 B：命令行执行
venv\Scripts\python.exe start_server.py

启动后：
- 默认浏览器会自动打开 http://127.0.0.1:5000
- 命令行窗口会显示本机地址和局域网地址
- 服务停止：按 Ctrl+C 或直接关闭命令行窗口


------------------------------------------------------------
四、常用配置（编辑根目录 .env）
------------------------------------------------------------
SERVER_HOST=0.0.0.0        # 0.0.0.0=本机+局域网；127.0.0.1=仅本机
SERVER_PORT=5000           # 端口被占用时改这里
SERVER_THREADS=8           # Waitress 工作线程数
OPEN_BROWSER=1             # 0=启动时不自动打开浏览器

DB_ENGINE=mysql            # 或 sqlite
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=123
DB_NAME=FactoryManagementSystem


------------------------------------------------------------
五、三个 bat 入口对照
------------------------------------------------------------
deploy_env.bat    只做部署（上面第 1~6 步），成功后退出，不启动服务。
run_system.bat    只做运行（启动 Waitress + 打开默认浏览器）。
启动系统.bat       先部署再运行，适合第一次部署或代码更新后使用。

------------------------------------------------------------
七、Linux / macOS 部署与运行
------------------------------------------------------------

前置条件：
- 已安装 Python 3（Debian/Ubuntu 可能还需：sudo apt install python3-venv）
- 若使用 MySQL，先启动数据库服务，例如：
  sudo systemctl start mysql      # 或 mariadb
  并确认 .env 中的 DB_* 与实际一致。

首次赋予脚本执行权限（一次即可）：
chmod +x deploy.sh run_system.sh start.sh

方式 A（推荐，脚本一键）：
./start.sh                  # 先部署再运行
或：
./deploy.sh                 # 只部署，不启动
./run_system.sh             # 只运行，启动后按 Ctrl+C 停止

方式 B（手工按顺序执行，在项目根目录）：
python3 -m venv venv
venv/bin/python -m pip install --upgrade pip setuptools wheel
venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
venv/bin/python scripts/ensure_database.py
venv/bin/python -m flask db upgrade
venv/bin/python -m flask db current
venv/bin/python scripts/seed.py
venv/bin/python start_server.py

说明：
- Linux/macOS 下不需要 bat，也不依赖 Windows 路径。
- 纯服务器/SSH 无图形界面时，run_system.sh 会自动设置 OPEN_BROWSER=0，
  只在终端打印访问地址；有桌面的环境会打开默认浏览器。
- 三个脚本对照：
  deploy.sh       只部署（对应 deploy_env.bat）
  run_system.sh   只运行（对应 run_system.bat）
  start.sh        先部署再运行（对应 启动系统.bat）
